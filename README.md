# Project 5 - TriviaGame

Submitted by: Angelina Kimaz

TriviaGame is an app where users can have fun testing their knowledge with different trivia questions.
Before starting, users can choose how many questions they want, the category, difficulty, and type of questions.
Once they finish answering, they can submit their answers and see how well they did.

Time spent: 6 hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] App launches to an Options screen where user can modify the types of questions presented when the game starts. Users should be able to choose:
  - [x] Number of questions
  - [x] Category of questions
  - [x] Difficulty of questions
  - [x] Type of questions (Multiple Choice or True False)
- [x] User can tap a button to start trivia game, this presents questions and answers in a List or Card view.
- [x] Selected choices are marked as user taps their choice (but answer is not presented yet!)
- [x] User can submit choices and is presented with a score on trivia game.

## Optional Features

The following **optional** features are implemented:

- [ ] User has answer marked as correct or incorrect after submitting choices (alongside their score).
- [ ] Implement a timer that puts pressure on the user! Choose any time that works and auto submit choices after the timer expires.
